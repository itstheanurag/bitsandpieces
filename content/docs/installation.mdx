# Installation

Bits&Pieces is designed to be copy-pasted into your project. Use our CLI to make this even easier.

## CLI

Run the `init` command to set up your project:

```bash
npx bitsandpieces init
```

## Adding Components

To add a component, use the `add` command:

```bash
npx bitsandpieces add button
```

This will copy the component code into your `components/ui` directory.

## Manual Installation

If you prefer, you can browse the [components](/browse) and copy the code manually.
