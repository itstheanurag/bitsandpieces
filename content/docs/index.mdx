# Introduction

Welcome to **Bits&Pieces**, a collection of high-quality, unstyled React components built for speed and accessibility.

## Features

- **Copy & Paste**: No npm install required for components.
- **Tailwind CSS**: Styled with utility classes you know.
- **Accessible**: Built on standard accessible primitives.
- **Open Source**: MIT Licensed.
