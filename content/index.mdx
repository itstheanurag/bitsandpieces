# Introduction

Welcome to **Bits&Pieces**, a collection of high-quality React components built for speed, accessibility, and pixel-perfect aesthetics.

## Why Bits&Pieces?

- **Copy & Paste** — No npm install required. Just copy the component code.
- **Tailwind CSS** — Styled with utility classes you already know.
- **Accessible** — Built on accessible primitives with ARIA support.
- **Customizable** — Easily adapt to your design system.
- **Open Source** — MIT Licensed and community-driven.

## Getting Started

Check out the [Installation](/docs/installation) guide to set up your project, then explore our components.

## Featured Components

Our component library includes:

- **Animated Form** — Progressive form with smooth animations
- **Animated OTP** — One-time password input with transitions
- **Bot Detection** — Human verification components
- **Social Cards** — Beautiful social media link previews
- **And many more...**

## Design Philosophy

We believe UI components should be:

1. **Fast** — No heavy dependencies or runtime overhead
2. **Beautiful** — Premium aesthetics out of the box
3. **Flexible** — Easy to customize and extend
4. **Accessible** — Usable by everyone
