## Step Configuration

The `steps` prop takes an array of objects with the following properties:

| Property           | Type        | Description                                                       |
| :----------------- | :---------- | :---------------------------------------------------------------- | ------ |
| `fieldName`        | `FieldName` | The key used in the form data. Must match a supported field type. |
| `fieldLabel`       | `string`    | The label displayed above the input.                              |
| `fieldDescription` | `string`    | Optional text displayed below the input.                          |
| `fieldIcon`        | `ReactNode` | Optional icon displayed next to the label.                        |
| `validate`         | `function`  | Optional validation function: `(value, formData) => string        | null`. |

## Features

- **Dynamic Workflows**: Define any sequence of fields from the supported registry.
- **Per-step Validation**: Prevent navigation until the current step is valid.
- **Animated Transitions**: Smooth slide-and-fade effects using `motion`.
- **Progress Tracking**: Automatic progress bar that updates as users advance.
- **Smart Fields**: Built-in support for various types (Email, Password, Credit Card, etc.) with appropriate input attributes.
