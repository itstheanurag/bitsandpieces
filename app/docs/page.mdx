# Bits&Pieces Documentation

Welcome to **Bits&Pieces**, a high-performance, meticulously crafted UI toolkit built for Next.js, React, Tailwind CSS, and Framer Motion. Our components are designed not just to be beautiful out of the box, but perfectly extensible and accessible.

<DocsCards />

## Design Principles

Bits&Pieces was built from the ground up with these core philosophies:

1. **Zero Abstraction** — You don't install a heavily bundled package. You copy the source code directly into your codebase. You own the code.
2. **Beautiful by Default** — We obsessed over typography (`Outfit` and `JetBrains Mono`), smooth Framer Motion micro-interactions, and high-contrast dark modes so your apps look like premium SaaS tools on day one.
3. **Tailwind Native** — Every component leverages standard Tailwind v4 utility classes. No proprietary styling languages to learn.
4. **Accessible Primitives** — We utilize Headless UI / Radix primitives where necessary to ensure ARIA compliance, focus management, and keyboard navigation.
