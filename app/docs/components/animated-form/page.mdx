## Step Configuration

Each item in the `steps` array is a `MultiStepFormStep`:

| Property      | Type                      | Description                                     |
| :------------ | :------------------------ | :---------------------------------------------- |
| `title`       | `string`                  | Optional title shown in the step indicator.      |
| `description` | `string`                  | Optional description displayed in the step body. |
| `fields`      | `MultiStepFieldConfig[]`  | One or more fields rendered in this step.        |

### Field Configuration

Each field in a step's `fields` array is a `MultiStepFieldConfig`:

| Property           | Type                                            | Description                                        |
| :----------------- | :---------------------------------------------- | :------------------------------------------------- |
| `fieldName`        | `string`                                        | Unique key used in the form data object.           |
| `fieldLabel`       | `string`                                        | Label displayed above the input.                   |
| `placeholder`      | `string`                                        | Placeholder text for the input.                    |
| `type`             | `HTMLInputTypeAttribute`                        | Input type — defaults to `"text"`.                 |
| `fieldDescription` | `string`                                        | Helper text displayed below the input.             |
| `fieldIcon`        | `ReactNode`                                     | Optional icon displayed next to the label.         |
| `validate`         | `(value: string, formData) => string \| null`   | Return error string to block, or `null` to pass.  |

## Features

- **Multi-Field Steps**: Group related fields together in one step.
- **Per-step Validation**: Prevent navigation until all fields in the current step are valid.
- **Directional Animations**: Forward slides right-to-left, back slides left-to-right.
- **Step Indicator**: Numbered circles with optional labels and check marks for completed steps.
- **Progress Bar**: Automatic progress bar that updates as users advance.
- **Accessible**: ARIA attributes for live error regions, step groups, and navigation.
- **Fully Generic**: No hardcoded field types — use any `fieldName` and `type` you need.
