# Bits Overview

This section provides an overview of the various "Bits" design utilities available in the BitsAndPieces library. These are small, reusable design tokens and utility classes that can be copied and used directly in your projects.

## Available Bits

- [Borders](/docs/bits/borders)
- [Shadows](/docs/bits/shadows)

Explore the sub-sections to see examples and usage instructions for each bit.
