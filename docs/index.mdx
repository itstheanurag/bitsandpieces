# Welcome to BitsAndPieces Documentation

This documentation serves as a comprehensive guide to using the BitsAndPieces library, a collection of modern React components and design utilities.

Here you will find:

- **Bits**: Reusable design utilities like borders and shadows.
- **Pieces**: Full-fledged React components such as buttons and navigation bars.

Use the navigation on the left to explore the different categories and components.
